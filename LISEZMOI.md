# Calcul Immo Locatif

Application de simulation d'investissement locatif (projet, financement, rentabilité, impact fiscal, investisseur).

- `index.html` : l'application complète (un seul fichier).
- `img/` : les images.
- `taux.json` : derniers taux du baromètre Meilleurtaux, lus par l'appli.
- `.github/workflows/taux.yml` + `scripts/` : mise à jour automatique de `taux.json` chaque matin.

Site publié avec GitHub Pages : Settings > Pages > Deploy from a branch > main / (root).
